STEP 4 - CHANGING A PASSWORD, ROLE OR AREAS LATER (any time, no redeploy
needed) - ALSO HOW TO ADD A NEW AREA MANAGER
---------------------------------------------------------------------
Log into the dashboard as Alagu (Owner). Open the small account panel
near the top (tap it to expand) - you'll see an "Admin" section that
only you can see.

To add a brand-new Area Manager (a new person who should only see certain
DSR areas): type their name in "...or type a new name", set Role to
"Area Manager", type the exact DSR card names they should see in the
Areas box separated by commas (e.g. Prabha,Arun), set a starting
password, re-type YOUR OWN current password to confirm, and Save. Yes -
whatever you list in the Areas box is the ONLY data that person will ever
see anywhere on the dashboard (cards, totals, rankings, Top 5, share
texts, usage report of DSR logins) - everything outside those areas is
left out completely, the same way each individual DSR app only ever
shows that one DSR's own data.

To change an EXISTING person: pick them from "Select user..." (this
auto-fills their current Role, Areas, and "Hide these people's logins"
box so you can't accidentally change any of them by mistake), adjust
whichever box needs changing, type their new password, re-type YOUR OWN
current password to confirm, and save. Takes effect immediately - that
person's next login uses the new password/role/areas/hidden-logins list.

Areas is required and can't be left blank when Role is "Area Manager" -
the page will stop you and ask for at least one area. Leave it blank for
Manager/DSR/Owner (Manager = sees everything).

"Hide these people's logins from THIS person" is a separate box, for the
usage report only - it doesn't affect Areas/DSR data at all. It's
one-directional: whatever names you type there are hidden ONLY from the
currently-selected person, not from anyone else. Leave it blank for
anyone who shouldn't have anyone hidden from them.
